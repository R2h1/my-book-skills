# 隧道效应与不平等容忍度

## R — 原文引用

> "隧道效应：当人们看到周围有人先富起来时，如果预期自己将来也能富，就会容忍当下的不平等。但如果隧道堵车了——自己一直没有动而别人在前进——不满就会爆发。"

## I — 方法论重述

隧道效应解释了为什么人们对不平等的心态会从'容忍'转向'愤怒'。关键在于**预期**而非现状：

- 增长初期：别人先富起来 → 我觉得自己也有机会 → 容忍不平等
- 增长放缓/停滞：别人还是在前面，但我看不到自己的机会 → 隧道堵车 → 不满爆发

这个模型对政策制定者的启示是：单纯的'缩小贫富差距'不如'保持社会流动性'重要——人们能接受有人比自己有钱，但不能接受自己没有上升通道。

## A1 — 书中案例

本书第五章用隧道效应分析了中国城市化过程中的不平等问题：虽然农民收入在增长（不患寡），但与城市居民收入的差距在扩大（而患不均）。当经济增长放缓、社会流动性下降时，隧道效应从正向转为负向，社会不满加剧。

## A2 — 调用时机 ★

- 你发现社会舆论对贫富差距的情绪突然转变
- 你在分析和预测社会稳定性风险
- 你设计收入分配或社会福利政策
- 你研究民粹主义兴起的根源

## E — 执行步骤

1. **判断隧道阶段**：经济是否在增长？社会流动性是否在增强？→ 决定隧道效应的方向
2. **观察预期变化**：人们对未来的预期是乐观还是悲观？预期变化比现状变化更重要
3. **寻找堵车信号**：哪个群体的上升通道被堵塞了？找到'堵车'的位置

## B — 边界

- 隧道效应是社会学模型而非精确预测工具
- 不同文化和社会背景下的'预期'差异很大
- 社交媒体可能放大不满情绪，使隧道效应加速转变
- 不适用于极端不平等社会（隧道已经塌了）
