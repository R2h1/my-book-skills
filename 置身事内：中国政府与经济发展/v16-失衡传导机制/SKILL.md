# 国内国际失衡传导机制

## R — 原文引用

> "国内国际失衡：重生产轻消费的经济结构造成出口依赖，贸易冲突是国内失衡的外部表现。……问题不仅仅是贸易问题，而是国内治理结构的问题。"

## I — 方法论重述

失衡的完整因果链：

**地方政府重生产轻消费 → 产能过剩 → 依赖出口消化 → 贸易顺差 → 贸易摩擦 → 外部压力**

核心洞察：贸易冲突不是"别人不守规则"，而是国内经济结构失衡的外部表现。只要重生产、轻消费的模式不变，产能过剩就会持续要求出口市场，对全球市场的冲击就不会消失。

## A1 — 书中案例

本书第七章分析了中美贸易冲突：表面上看是关税和逆差问题，根子上是中国国内的结构失衡——居民收入占比偏低、消费不足、高储蓄率、产能过剩。即使美国不加关税，其他国家的保护主义也会抬头。

## A2 — 调用时机 ★

- 你分析中美贸易冲突的根源
- 你研究"双循环"政策背后的逻辑
- 你想理解为什么中国有如此高的储蓄率
- 你评估出口依赖型经济的脆弱性

## E — 执行步骤

1. **看国内结构**：消费/GDP占比、居民收入/GDP占比 → 判断是否失衡
2. **看产能消化**：产能 > 国内需求的部分去了哪？→ 出口还是库存？
3. **看外部反馈**：贸易伙伴的反应是什么？关税、反倾销、技术封锁？
4. **判断恶性循环**：外部压力 → 更依赖投资和出口？还是倒逼内部改革？

## B — 边界

- 不适用于小国经济（小国可以高度依赖出口而不会引发贸易摩擦）
- 技术升级（如新能源车领先全球）可能改变比较优势格局
- 全球产业链重构（如去全球化趋势）会改变传导路径
- 不适用于纯服务贸易（中国服务贸易长期逆差）
