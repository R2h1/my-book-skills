# 产业政策评估与退出机制

## R — 原文引用

> "所以产业政策要有退出机制，若效率低的企业不能退出，'竞争性'就是一句空话。'退出机制'有两层含义。第一是政策本身要设计退出机制……第二是低效企业破产退出的渠道要顺畅。"

## I — 方法论重述

评估产业政策是否合理的四个维度：
1. **合理性**：这个产业是否具有较大的学习效应和规模效应？是否可能创造新的比较优势？
2. **竞争性**：政策是否保持了市场竞争？政府是'培育市场'还是'替代市场'？
3. **退出机制**：政策是否有明确的时间表和退出条件？补贴是否会逐步递减？
4. **执行能力**：地方政府是否有能力识别和扶持优质企业？是否有配套的配套条件？

产业政策最容易失败的地方不是'选错产业'，而是'扶持了对的企业却无法退出'——政策一旦启动就有利益集团固化，低效企业无法破产，竞争失去意义。

## A1 — 书中案例

本书第四章以中国光伏产业为例：政府早期扶持光伏（2000年代），通过上网标杆电价等政策创造了巨大市场。政策驱动下产能迅速扩张，但补贴退出机制设计不足，导致2011-2012年全行业严重产能过剩，龙头尚德和赛维破产。京东方（显示面板）则是较为成功的案例——政府持续投入、企业坚持技术创新、最终形成了国际竞争力。

## A2 — 调用时机 ★

- 你评估政府对某个新兴产业的扶持政策
- 你判断一个'风口'行业是否值得政府投入
- 你分析某个行业的补贴政策风险
- 你研究产业政策成功与失败的案例

## E — 执行步骤

1. **评估产业特性**：是否有学习效应和规模效应？技术复杂度如何？
2. **检查退出机制**：补贴是否设定了递减时间表？低效企业能否破产退出？
3. **判断政府能力**：地方政府是否有足够的专业能力识别和监管？
4. **风险收益比**：成功的回报是否大于失败的代价？

## B — 边界

- 不适用于成熟产业（没必要再用产业政策）
- 政府能力极弱的情况下，任何产业政策都可能是浪费
- 无法预测颠覆性技术带来的产业洗牌
