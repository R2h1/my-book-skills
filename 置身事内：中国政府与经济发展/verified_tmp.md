  passed: true
  novel_question: "在AI监管、自动驾驶等新技术领域，应该由中央政府统一立法还是地方政府先行先试？"

  passed: true

title: 形式权威 vs 实际权威
source_chapter: 第一章
type: framework
V1_cross_domain:
  passed: true
  evidence:
    - "第一章政府组织：上级拥有形式权威，下级因信息优势拥有实际权威——选择性汇报、拖沓执行、频繁请示都是下级行使实际权威的方式"
    - "第三章城投公司运作：市政府在形式上拥有对城投公司的决策权（形式权威），但城投公司因为掌握项目具体信息和银行关系，在实际运作中有很大自主权（实际权威）"
    - "第四章产业政策：中央制定产业方向（形式权威），地方政府在具体扶持企业、提供优惠时拥有实际裁量权（实际权威）"
V2_predictive_power:
  passed: true
  novel_question: "为什么中国很多'垂直管理'改革（如环保、央行、银保监）虽然形式上收回了权力，但实际效果往往不如预期？"
  derived_answer: "垂直管理改革将形式权威上收，但并未改变信息分布——被管理对象仍主要由地方政府了解。上级监管机构缺乏本地信息（信息劣势），被迫依赖地方政府提供数据，实际上地方政府仍保留大量实际权威。这解释了为什么环保督察需要中央派出（以弥补信息劣势），也解释了为什么央行分支行在地方执行货币政策时仍有'变通空间'。"
V3_exclusivity:
  passed: true
  why_not_common: "形式权威与实质权威的区分虽然源于组织理论（Aghion & Tirole 1997），但在中国语境下被赋予了新的分析维度：选择性汇报、频繁请示作为下级保留实际权威的策略，以及一把手负责制作为实际权威高度个人化的体现。这些具体机制的分析是本书独特贡献。"
