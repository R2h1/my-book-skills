# GLOSSARY — 全书共享术语词典
> 《金钱的属性：一个富豪的财富私房课》金胜镐。所有 skill 共享的概念定义。注意作者用法与字典义的差异（`≠` 表示与常识用法的区别）。

| 术语 | 作者的定义（原文/改写） | 与常识用法的差异 | 相关 skill |
|------|------------------------|------------------|-----------|
| **金钱的属性 / 金钱就是人** | 金钱像人一样有品性、有好恶、会回应主人态度 | ≠ "钱的特征"（中性）；= 一套把金钱拟人化、以"待人之道"待钱的心智模型 | v01, v19 |
| **固定收入 / 不固定收入** | 固定现金流（工资/房租/分红）质量高、能控风险；一次性大钱质量低、易挥霍 | ≠ 按金额衡量收入；= 按"节奏/可预测性"衡量 | v05, v03 |
| **种子钱（引水）** | 能启动"金钱引力/复利"机制的阈值本金（约先攒1000万，再到1亿） | ≠ 泛指"一点启动资金" | v06, v08 |
| **良债 / 劣债** | 良债=用于产生收益且ROE>利息、可控；劣债=消费、失控、利息吞噬现金流 | ≠ "债务都是坏的"；债务性质由用途决定 | v07, v04 |
| **金钱的引力** | 财富按倍数（1,2,4,8,16）增长；越大的资本越吸引资本 | ≠ 模糊的"钱生钱"；= 可量化的乘法增长机制 | v06, v04 |
| **个人独立纪念日** | 资本（被动）收入首次 > 劳动收入的那一天 | ≠ 模糊的"财务自由"；= 可判定、可纪念的节点 | v03, v05 |
| **PER（市盈率，个人化）** | 收入能否脱离本人而持续（医生/博主 PER≈0；版权/房租/系统 PER 高） | ≠ 只用于股票估值；= 自我诊断"你的收入是不是真的收入" | v03, v05 |
| **接住落下的刀** | 恐慌致股价低于内在价值时分批买入（戴皮手套：懂价值+分批+无杠杆） | ≠ "别接飞刀"；作者反直觉但限定条件严格 | v14, v09 |
| **教练 vs 选手** | 资产配置（教练）比选标的（选手）重要约9倍 | ≠ 把精力放"选什么股票"；= 先布阵再选人 | v11, v12 |
| **漂亮的垃圾** | 买时漂亮、带回家无处安放、弃之可惜的消费 | ≠ 一般"浪费钱的物品"；= 炫耀性消费的诊断命名 | v20, v08 |
| **Quarter 准则** | 生活水平保持同等收入者的1/4，留3年危机缓冲 | ≠ 巴菲特式极端节俭；= 节俭与炫耀间的可执行标尺 | v20, v03 |
| **能久 / 功夫** | 持续行动 100 天/3 个月以改变自我 | ≠ 泛泛"坚持"；= 有刻度的自我改变周期 | v16 |
| **腹八分** | 吃八分饱的养生训诫迁移到赚钱/攒钱/投资：留余量、不贪 | ≠ 只是养生；= 投资与消费的克制纪律 | v20, v16 |
| **大富由天** | 小富由勤、大富靠时代/运气；核心是"知道运气的存在" | ≠ 宿命论；= 运气认知框架 | v23, v16 |
| **分散投资（篮子 vs 架子）** | 分散必须跨资产大类；同市场多品种只是"同一架子的多个篮子" | ≠ "多买几只=分散" | v12, v11 |
| **现金流** | 现金流入流出的节奏；企业/个人缺稳定现金流会"窒息" | ≠ 只看利润；= 强调"持续流入" | v05, v07 |
| **资产配置** | 按目标/风险/期限把资金分配到大类的顶层设计 | ≠ 选股/择时；= 收益的大部分来源 | v11, v12 |
| **复利（作者用法）** | 复利是中性的：储蓄/投资上是朋友，债务上是敌人 | ≠ 只强调"复利是奇迹"；= 双刃剑 | v04, v15 |

## 使用说明

- 以上术语在 26 个 skill 中均按此定义使用，请勿沿用字典义。
- 数字（1000万/1亿、10亿/50亿韩元、276万等）均为作者韩国背景的经验值，使用时按当地购买力折算，作为"量级直觉"而非精确公式。
