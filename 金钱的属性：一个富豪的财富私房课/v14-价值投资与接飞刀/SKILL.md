# 价值投资与接飞刀：懂价值，戴皮手套接刀

## R — 原文 (Reading)

> 为了能抓住落下的刀，要了解公司的价值而不是价格。当市场价格跌落至价值以下时，要分批买入。……皮手套的一只是分批买入，另一只是对企业价值的信心。
>
> — 金胜镐, 《能抓住落下的刀的人》

## I — 方法论骨架 (Interpretation)

"别接飞刀"是对技术投机者说的；**对懂价值的人，刀落下之时就是买入之际**。但接刀必须"戴皮手套"：

1. **看价值不看价格**：股价暴跌 ≠ 公司价值受损。要判断的是"内在价值"，不是"K线"。
2. **读财报（成绩单）**：买股票前先看"商品评论"——财务报表。成长初期看销售额、之后看营业利润、最关键看现金流（现金周转不畅会破产）。"给自己当老板，花一整天研读目标公司财报"。
3. **分批买入 + 不用杠杆**：两副皮手套——分批（分3-5档）降低恐惧与择时错误，绝不用保证金/杠杆。
4. **分批的唯一底气是对价值的信心**：如果你不确定价值，接刀就是赌博。

作者自述年轻时用"走势图分析"（技术投机）亏光全部财产、20年不敢碰股市——正是"不看价值只看价格"的教训。

## A1 — 书中的应用

- 作者年轻时学"走势图分析训练技巧"初次炒股，亏光所有财产、欠债、患脱发，20年不碰股市——反面教材（投机 vs 投资）。
- 作者建议"把自己想象成某家企业的老板，用一整天仔细查看这家企业的财务报表"，看不懂就学（他甚至为学会计一次买30余本会计书）。
- 作者在暴跌中接刀的操作原则：分批购买、不使用保证金、在合理价值以下购买；"真希望有一个以价值为中心而不是以买卖为中心解读投资的电视台"。

## A2 — 触发场景 ★

**场景**：某优质公司股价因利空暴跌，你想判断该不该买；你想学"怎么用财报判断公司价值"；你想建立"分批买入"的纪律；你反思自己"抄底总是抄在半山腰"。

**语言信号**：
- "跌了40%是不是机会？"
- "怎么判断一家公司值多少钱？"
- "财报该看哪些指标？"
- "为什么我抄底总是亏？"

**相邻区分**：与"风险与恐惧的逆向"（v09）配合——v09 判断"该不该在恐惧时买"，本 skill 给出"买什么/怎么买（看价值、分批）"；与"投资优秀经营者"（v13）配合——v13 选"买谁"，本 skill 判断"多少钱买/何时买"。

## E — 执行步骤

1. **先读财报**：对目标公司，读其年度报告/财报，重点看：销售额（成长初期）、营业利润（基础经营是否健康）、现金流（会不会断）、债务水平。判断"内在价值是否受损"。

2. **估一个"合理价值"**：基于现金流/盈利给出你自己的合理价（不需要精确，给自己一个价值区间）。价格 > 价值 → 不买；价格明显 < 价值 → 进入下一步。

3. **制定分批计划**：把计划买入资金分成 3-5 档，按价格每下跌一定幅度买一档；不用杠杆、不用急钱（v10）。

4. **执行 + 复盘**：分批买入后长期持有（v15）；每次"抄底"后复盘——是价值判断还是情绪抄底？逐步训练价值判断力。

## B — 边界 ★

- 不懂价值判断的抄底 = 赌博：新手在学会看财报（本 skill + 大量学习）前，别"接刀"，可先用"恐惧时不割肉+不追高"保命（v09）。
- 财报可能造假/滞后；"成绩单好"不等于"未来好"（学习好可能泯然众人），价值判断要结合行业与时代。
- 分批买入在"价值持续崩塌"（基本面真的坏了）时会越买越亏——所以第一步"价值是否受损"是硬前提。
- 作者的20年不碰股市说明"方向错了代价极大"：投机/追高的损失可能让你数年无法翻身。
