# 富人四种能力：挣钱、攒钱、保值、消费

## R — 原文 (Reading)

> 这四种能力分别是赚钱的能力、攒钱的能力、保值的能力、消费的能力。……这四种能力就像摆满山珍海味的饭桌的四条桌腿，哪怕只有其中一条桌腿太短或者荡然无存了，一桌子满满的菜肴也早晚都会呼呼啦啦地瞬间倒塌。
>
> — 金胜镐, 《管理金钱的四种能力》

## I — 方法论骨架 (Interpretation)

财富管理不是一种能力，而是四种彼此独立、缺一不可的能力，像餐桌的四条腿：

1. **挣钱能力**：外露、进取、擅长销售与经营（富人最常见、最被高估的能力）。
2. **攒钱能力**：支出管理、资产均衡、处理发票/税率/汇率等细节，尊重小钱。
3. **保值能力**：守财最难——攻城容易守城难，奢侈虚荣、不再学习、不做正确投资都会让城墙瞬间崩塌。
4. **消费能力**：像高超的政治技术——该付的准时付、该花的舍得花、但俭朴不吝啬、不为虚荣请客。

核心洞察：**会赚钱不代表会理财**。很多高收入者恰恰缺后三种能力，导致"赚着大钱却没有赚钱的感觉""财产到手后又花光""被诈骗""被手下贪污"。

## A1 — 书中的应用

- 宋老板甜品店生意火爆、不断研发新菜单，却把100%收益再投入研究室，结婚20年没有房子——**只有挣钱能力、缺攒钱与保值平衡**，作者判定他"绝对成不了富人"。
- 作者指出"赚了钱却不懂积攒，和没底的缸别无二致"：会赚钱的人若不补攒钱/保值，财富从窟窿里外泄。
- 作者提出"消费能力"的细则：给父母零花钱要像发工资一样固定日期准时分毫不差；约了美发师取消也要付费；听律师建议要付咨询费而非请吃饭。

## A2 — 触发场景 ★

**场景**：你月入很高却存不下钱；你赚到一笔钱后很快花光；你被推销/诈骗/下属坑过；你想系统评估自己的财商短板；你想知道"我该补哪项能力"。

**语言信号**：
- "我挺能挣的，就是留不住钱"
- "如果我只负责在外面赚钱该多好"
- "赚的钱怎么不知不觉就没了"
- "我不知道该怎么守财 / 怎么花钱"

**相邻区分**：与"富人标准"（v03，判断你算不算富人）不同，本 skill 诊断"你能不能守住并壮大财富"；与"攒钱机制"（v08）不同，本 skill 是四维能力全景自评，v08 是其中"攒钱"腿的具体工具。

## E — 执行步骤

1. **四能力自评**：用 1-10 分给"挣钱/攒钱/保值/消费"四项打分（参考书中描述的行为特征），找出最短的那条"桌腿"。

2. **补短板（按最短腿优先）**：
   - 缺攒钱 → 用 v08 攒钱机制（剪卡/分账）
   - 缺保值 → 列一份"守财清单"：停止炫耀性消费、继续学习投资、审查现有投资是否在"正确投资"
   - 缺消费 → 练习"准时支付+该付就付+不虚荣请客"

3. **检查家庭现金流结构**：对照宋老板教训——你的收益是否有固定比例流向家庭资产（如一半交给配偶）？若没有，设立"家庭资产账户"，每月/每季转入固定比例。

4. **设置复查点**：每月末用同一张四能力评分表复查，看最短腿是否在改善。

## B — 边界 ★

- 四能力是诊断框架，不是精确量表；评分是主观的，用于定位方向而非打分竞赛。
- 高收入者在"挣钱"腿得高分很正常，别因此忽视其他腿；四条腿都短的人（收入也不高）应从"攒钱"起步。
- 作者的价值观（家庭共同财产、不虚荣请客）带个人色彩，可调整；本 skill 的核心是"四种能力要平衡"而非特定分配比例。
- 不解决"没收入怎么变富"——那是 v24 职场/创业路径的问题。
