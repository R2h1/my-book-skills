# 对待他人金钱的态度：就是对待自己金钱的态度

## R — 原文 (Reading)

> 公款、税金、会费、朋友的钱、父母的钱都属于他人的钱。对待他人的金钱的态度才是一个人对待金钱的真实态度。……不随意对待他人的金钱，自己的金钱也就不会被他人随意对待。
>
> — 金胜镐, 《对待他人金钱的态度就是对待自己金钱的态度》

## I — 方法论骨架 (Interpretation)

**你怎么对待别人的钱，暴露了你真正怎么对待钱**——因为对自己的钱人们都会"装"出珍惜，只有在面对"别人的钱"时才露出真实态度：

1. **公款/税金/会费/朋友的钱/父母的钱 = 他人的钱**：随意对待它们（逃税、浪费公物、朋友请客点贵的、聚餐多要酒）= 你实际在随意对待自己的钱。
2. **反向同理**：尊重他人的钱，自己的钱才会被尊重——就像"要想获得尊重，先尊重他人"。
3. **一切公共设施都含你的钱**：以税金建设的道路、公共设施、医疗服务都包含你自己的金钱，逃税等于偷盗他人的钱（合法节税是保护，逃税是蔑视）。
4. **细节见真章**：用公款点贵的菜、聚餐占便宜、故意破坏公物、耍伎俩申请补助——这些细节足以衡量一个人对待金钱的真实态度。

延伸到家庭：对父母/家人金钱的尊重（v26 家族首富之道）也是本框架的延伸。

## A1 — 书中的应用

- 作者年轻时经营超市，每年因购物车丢失/毁损损失2万美元以上，因此即使现在作为顾客也主动把开市客停车场散落的购物车推进店内——"因为我是持有开市客0.003%股份的股东，购物车的一个轮子也算我的东西"。
- 作者自述：即便100%持股的公司，他也只用企业法人卡做公司事务；去自家卖场也一定自己掏钱——"在这种情况下，哪怕一元钱都是属于他人的钱"（因为影响经理业绩）。
- 作者批评：有人拼命省自己的钱，用公款/税金却毫不在意，朋友请客时专点贵菜——这些态度会腐蚀金钱观。

## A2 — 触发场景 ★

**场景**：你在面对公款/报销/聚餐/借用他人财物时；你想判断一个行为是否"越界"；你发现自己在占小便宜；你想培养"待钱如人"的品格（配合 v01）。

**语言信号**：
- "反正不是我的钱，用点没关系吧"
- "朋友请客，点贵的尝尝"
- "这钱是公家的，省什么"
- "占这点小便宜无所谓的"

**相邻区分**：与"金钱即人"（v01）配合——本 skill 是"金钱即人"在"他人金钱"上的具体化；与"家族首富相处之道"（v26）配合——v26 是家庭场景的操作版；与"消费观漂亮垃圾"（v20）不同——本 skill 关于"对待他人的钱"，v20 关于"对待自己的消费"。

## E — 执行步骤

1. **建立"他人金钱"清单**：列出你日常接触的"他人金钱"场景（公款、税金、AA、朋友请客、借用），标注你现在的态度。

2. **行为自检（7天）**：接下来一周，观察自己在这些场景的行为——是否点贵的、是否浪费公物、是否占小便宜；记录"暴露真实态度"的时刻。

3. **执行"尊重动作"**：选一个立刻可做的尊重行为（主动收拾公共区域的购物车/垃圾、AA时主动结清、不用公款办私事），坚持执行。

4. **升维到税金/公共**：把"税金/公共设施包含自己的钱"当事实内化——合法节税、按时纳税，把"尊重他人金钱"变成自动反应。

## B — 边界 ★

- 这是品格/价值观框架，不是法律或财务建议；"合法节税"与"逃税"有明确边界，别把"合理避税"与"偷漏税"混淆。
- 不必过度到"不敢用别人一分钱"的极端：正常的AA、合理的公共使用是正当的；本 skill 针对"随意/占便宜"的态度。
- 作者的叙事（"金钱会记仇"）是拟人化表达，别当成因果律；核心是"行为塑造金钱观"的自我管理。
- 不适用于计算具体税务/财务安排（那是专业问题）。
