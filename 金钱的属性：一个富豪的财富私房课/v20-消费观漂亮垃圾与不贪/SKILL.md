# 消费观：漂亮的垃圾与不贪（腹八分）

## R — 原文 (Reading)

> 有些东西，即便再漂亮，也是垃圾。垃圾就应该被丢掉或被收走，没理由花着钱被垃圾的美丽诱惑。……投资时不要贪得无厌，就好比在肚子饱之前就起身是最为长久地维持健康生活的方法。
>
> — 金胜镐, 《漂亮的垃圾》/《头凉足暖腹八分》

## I — 方法论骨架 (Interpretation)

把"消费"从"证明我是谁"（炫耀）转回"我真正需要什么"（需要），并用"腹八分"的留余量纪律约束欲望：

1. **漂亮的垃圾过滤器**：买之前先问"它会不会成为漂亮的垃圾"——买时漂亮、带回家无处安放、弃之可惜。富人的消费从"为了炫耀"转向"因为需要"：奢侈品可有可无，真正值得花的是体验、回忆、好的床、好的椅子、定制手工鞋。
2. **腹八分（留余量）**：吃八分饱最健康，赚钱/攒钱/投资同理——投入与消费留余量、不贪到最后一口。卖出之难在于贪婪，扼制贪婪才能成功卖出。
3. **远离暴利（快钱是毒品）**：预期收益过高 = 风险过高 + "快钱上瘾"会摧毁你对正常收益率的耐心（配合 v22 免遭诈骗）。"快速得来的金钱也会快速消失"。
4. **不要让自己显得像富人**：成为富人之前，所有资产都应用来创造其他资产；品位聚拢金钱，但奢侈不是品位。

## A1 — 书中的应用

- 作者与妻子进行"世界上最贵的旅行"（私人飞机、9国），却几乎不买纪念品——只买了一双拖鞋和一个卡包；妻子只买了一个花瓶。他们主动避开"俄罗斯套娃、河内草帽、日本和服、水晶球、挺嘎挺嘎画作"这些"漂亮的垃圾"。
- 作者自述：名品"有也行没有也行"，现在反而戴200美元的瑞士国铁表而非劳力士——消费从炫耀转向需要。
- 作者用"腹八分"管理投资：卖出的难度不亚于买入，难点正在贪婪；"面对恐惧可以缓缓随行，一旦出现贪婪就要远远逃离"。

## A2 — 触发场景 ★

**场景**：你被"好看/有面子"的物品吸引想买时；你被"高回报/暴利"项目诱惑时；你想改掉炫耀性消费习惯时；你反思"买了很多没用的东西"时。

**语言信号**：
- "这个好漂亮，必须买"
- "别人都有，我也想要"
- "这个项目三个月翻倍，投不投？"
- "我怎么买了这么多没用的东西？"

**相邻区分**：与"攒钱机制"（v08）配合——v08 是"钱放哪/怎么防漏"，本 skill 是"买什么/要不要买（消费决策）"；与"免遭诈骗"（v22）配合——"远离暴利"是防骗的共因；与"慢变富"（v16）配合——不贪是慢变富的消费面。

## E — 执行步骤

1. **漂亮的垃圾测试**：对想买的东西问三个问题：买回家有固定位置吗？一周后还用得上吗？是"需要"还是"炫耀"？三问任一不过关 → 列为"漂亮的垃圾"放弃。

2. **设冷静期**：非必需品（>一定金额，如月收入的1%）放进"愿望清单"，等待 30 天；30天后仍想要且仍需要，再买。

3. **腹八分自查**：对每一笔投资/大额消费，问"我是在留余量（腹八分）还是贪最后一口（吃太饱）？"——尤其卖出/获利时，不贪到顶。

4. **远离暴利红线**：把"预期收益过高（如>正常水平数倍）"设为红线，遇到一律拒绝（配合 v22），并把精力转回"慢慢变富"。

## B — 边界 ★

- "不贪/反消费"不等于苦行僧：作者的 Quarter 准则（v，生活按收入1/4）允许适度享受与奖励；本 skill 反对的是"炫耀性/无度"，不是"合理享受"。
- "漂亮的垃圾"是主观判断：对你有长期价值的东西（爱好、收藏）不在此列，别矫枉过正。
- 远离暴利要结合 v14 的价值判断：有些高收益是真实的（不是都骗人），但"看不懂/收益过高"时拒绝最安全。
- 消费观是个人选择，别人的消费方式不必评判；本 skill 帮助你找到自己的"需要 vs 炫耀"分界线。
