# 免遭诈骗：不贪，不碰不熟悉的领域

## R — 原文 (Reading)

> 我遭到诈骗最具决定性的原因就是我的无知和贪婪。……不贪婪，不让自己参与到不熟悉的领域中去，就能够避免自己上当受骗。远离所有能够获得巨大收益的提议，只在自己熟悉的领域之内进行投资。
>
> — 金胜镐, 《免遭诈骗的方法》

## I — 方法论骨架 (Interpretation)

诈骗的根源是**受害者自己的"无知 + 贪婪"**，而非骗子的高明。由此建立两道防骗过滤：

1. **拒绝"收益过高"的提议**：预期收益过高 = 风险过高。任何"稳赚/翻倍/只赚不亏"都同时命中"收益过高"，一律拒绝。
2. **拒绝"看不懂模式"的提议**：无法理解的生意模式，出问题时无法控制。作者拒绝提议的理由就两种：收益过高，或看不懂模式。
3. **只在自己熟悉的领域投资**：这是避免几乎所有诈骗的方法。
4. **别因"被当傻瓜"而动摇**：拒绝高收益提议常被嘲笑"你傻啊"——但作者宁被当傻瓜也不碰；"就算有风险的事情也要挑战"指的是事业，不是骗局。

作者用"割韭菜邮件实验"说明：给1万人各发"明天涨/跌"，连续5轮后剩下312人把他当股神——所谓的"预测高手"很多只是这种幸存者把戏。

## A1 — 书中的应用

- 作者年轻时被同一人连环诈骗四次：eMachines上市特权（股票成废纸）、实时股票排行交易公司、期权交易、外汇期货——移民10年的积蓄全部耗尽并负债。"是我是无知加贪婪造成了这样的结局"。
- 作者总结：从那之后他几乎不再被骗——"不贪婪、不碰不熟领域、拒绝过高收益"。
- 作者列出"拒绝的理由大致有两种：收益过高或者我无法理解生意模式"，并说"如果我拒绝还会被当作是傻瓜，但我无所谓"。

## A2 — 触发场景 ★

**场景**：有人给你"稳赚/高收益/内幕/保本"的投资机会时；你被"高回报项目"吸引时；你反思自己或被身边人被骗的经历时；你想建立一套自动的防骗反应时。

**语言信号**：
- "这个项目稳赚不赔，你要不要投"
- "我有内幕消息，只赚不亏"
- "错过了这个村就没这个店了"
- "收益这么高，是不是真的？"

**相邻区分**：与"独立判断"（v17）配合——不轻信是防骗第一闸；与"消费观漂亮垃圾与不贪"（v20）配合——"远离暴利/不贪"是防骗的心理根源；与"价值投资"（v14）配合——能看懂价值、懂财报的人更不容易被"高收益"骗。

## E — 执行步骤

1. **启动双过滤**：面对任何投资/生意提议，跑两道过滤：①预期收益是否过高（>正常水平数倍/"稳赚"）？②我是否真的懂这个模式？任一命中 → 拒绝。

2. **自查"无知+贪婪"**：问自己：我是不是因为"想快点赚大钱"（贪）或"其实不懂"（无知）才心动？若心动源于这两点，就是被骗的前兆。

3. **拖延+核实**：对任何"必须马上决定"的提议，一律拖72小时再说；用 v18/v17 的方法独立核实，不通过熟人/推荐人核实（他们可能是链条）。

4. **只投懂的+设上限**：只在自己熟悉的领域投资（v13/v14）；即使如此，也要用闲钱（v10）并设一个"最多亏损得起"的上限。

## B — 边界 ★

- 本 skill 是防骗心理/纪律框架，不能替代法律手段：已经受骗请立即报警/联系金融机构。
- "拒绝高收益"不等于拒绝所有好机会：真实的高回报投资存在（v14），关键是"看得懂 + 有价值依据 + 可承受"。
- 不要因为本 skill 而对所有提议都疑神疑鬼（那会滑向"什么都不信"）；它是"默认怀疑、证据说话"。
- 作者"只投熟悉领域"偏保守，可能错过新领域（AI等）红利；对想尝试新领域的人，应"先学习到看得懂再投"，而非永远回避。
