# 独立判断：专家预测不可信，投资必须自己决定

## R — 原文 (Reading)

> 贤明的投资者或专家被问及"这只股票会涨吗"这样的问题时，应该回答："我不知道。"……无论谁都不能够代替你做出决定。一定要自己独立判断、学习、做出决定。
>
> — 金胜镐, 《经济专家真能预测经济前景吗》/《对社会权威要经常心存怀疑》

## I — 方法论骨架 (Interpretation)

**经济/市场预测是不可能的**（400年证交所历史，无一人能持续正确预测）；专家的意见只是一种"意见"，不具绝对权威。由此建立独立判断的纪律：

1. **"我不知道"才是正确答案**：对"这只股票会涨吗""现在该买吗"——正确答案是"我不知道"。不知道时不危险，**自以为知道其实不知道才危险**。
2. **不押注他人预测**：把赌注押在专家意见上并拼上全部财产是最可怕的错误。专家只展示说对的、隐藏说错的（"对了是英雄，错了不犯罪"）。
3. **只信"长时间成功"**：判断一个人/理念是否可信，看它是否经受住最少一个世代（30年）的验证且仍在赚钱——不信"往年理论"、短期暴富者、无成果的理论家。
4. **对权威心存怀疑**：医生、律师、会计师、投资专家的意见都只是意见；高手既不会问买卖时机，也不会答。投资必须自己学习、独立决定。
5. **用常识识别阴谋论**：高知者反而易陷阴谋论（反感不确定性）；"你自己知道就行"的内部消息就是阴谋信号，用常识检验。

## A1 — 书中的应用

- 作者被问"今后股市上涨吗"一律不答：他"不知道市场下月/明年如何，但非常清楚5年后它会如何"——把预测放弃，把时间拉长。
- 作者年轻时在汝矣岛证交所被保安赶出，后来发现"至今还有人为了买三星股票去三星证券"——无知者思维30年不变，印证"要系统学习4年"（而不是听信证券职员）。
- 作者批判证券节目/专家："对价格进行预测、对走势图分析，却不评价企业价值"；占卜师一辈子靠"一次预测命中"宣传，忘了自己错过的更多。

## A2 — 触发场景 ★

**场景**：有人（专家/大V/理财顾问/亲戚）给你"稳赚"的预测或内幕时；你发现自己在追"推荐股票/板块"时；你被阴谋论或"内部消息"吸引时；你想建立"自己学习做决定"的习惯时。

**语言信号**：
- "这个专家/大V说得靠谱吗？"
- "帮我预测下市场会涨还是会跌"
- "他给我推荐了只稳赚的股票"
- "都说这次不一样，要不要信？"

**相邻区分**：与"新闻vs投资信息"（v18）配合——v18 处理"新闻里的事实与信息"，本 skill 处理"专家/权威的意见与预测"；与"免遭诈骗"（v22）配合——不轻信是防骗的第一道闸；与"价值投资"（v14）配合——独立判断的落点是自己读财报、自己估值。

## E — 执行步骤

1. **给"预测"打问号**：听到任何关于涨跌/时机/前景的判断时，先默念"他不知道（我也不知道）"——把它当作意见而非事实。

2. **追问证据**：问自己/对方：这是基于数据事实，还是观点/预测？他展示的是说对的还是全部？用 v18 的方法核对。

3. **独立学习补课**：把"问别人"换成"自己学"——用 v14 读财报、v13 选行业第一，建立自己的判断依据；给自己定一个学习计划（如4年入门）。

4. **权威测试**：对某个你崇拜的"专家/大师"，查他过去10年的判断记录——只信"长时间成功且仍在赚钱"的人，其余一律保留怀疑。

## B — 边界 ★

- "不信专家"不等于"闭门造车"：学习、读财报、参考多源信息是必要的；反对的是"把决定权交给别人"，不是"不学习"。
- 有些领域（医生治病、律师咨询）专业意见仍是重要参考；本 skill 主要针对投资/财富决策。
- 过度怀疑会滑向阴谋论或"什么都不信"——用常识（v18/v21）做平衡，怀疑但不偏执。
- 独立判断需要积累（读财报、看年报），短期内"不轻信+不乱动"比"自作聪明"更安全。
