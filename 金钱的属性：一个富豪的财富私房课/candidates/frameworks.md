# 候选框架池 — 《金钱的属性：一个富豪的财富私房课》
> 阶段 1 框架提取器产出（由主流程补写）。每条待阶段 1.5 三重验证。

- id: f01
  title: 金钱就是人（金钱人格化心智模型）
  type: framework
  source_chapter: 金钱就是人
  source_quote: |
    "金钱比起法人来是更加精准、具体的'人'。有些钱喜欢和人相处便会蜂拥而至，
    有些钱则躲躲藏藏独自度过一生。对小钱不屑一顾的人，终将失去大钱。"
  summary: |
    把金钱当作有品性、有好恶、会"记仇"也会"报恩"的实体来对待。用对待朋友的方式
    对待金钱：尊重小钱、不挥霍、用在该用的地方，金钱才会聚拢并带来更多金钱。
    这不是泛灵论，而是一套管理注意力的心智模型——它强迫你在每一笔支出/收入前
    先问"我这样对待金钱，金钱会怎么回应我"。
  tags: [mental-model, money, mindset]

- id: f02
  title: 金钱引力（财富倍数增长模型）
  type: framework
  source_chapter: 金钱具有引力的作用
  source_quote: |
    "财产增值的过程并不是以1、2、3、4、5这样的自然数形式增加的，而是按照
    1、2、4、8、16这样的倍数增长的。理解了这个原理，无论是谁都能成为富人。"
  summary: |
    财富增长不是等差的（攒多少是多少），而是乘法的（资本会自我繁殖）。因此关键不是
    "每期攒多少"，而是"攒下第一个种子钱（1000万/1亿）"——之后第二个、第三个
    种子钱所需的努力指数依次下降（100→95→20）。把注意力从"攒钱总量"转移到
    "尽早完成第一桶金"上。
  tags: [mental-model, wealth, compounding]

- id: f03
  title: 每分钱的时间属性（金钱的狭义相对论）
  type: framework
  source_chapter: 每分钱都有不同的时间流逝状态
  source_quote: |
    "根据不同的金额和来源，金钱也会呈现出不同的时间流逝状态。……最可怕的是通过
    杠杆融资进入的金钱。这笔钱就像食人族里的人一样上蹿下跳。"
  summary: |
    同一笔数额的钱，因来源和用途不同，可投资的"耐心"不同：要结婚的钱、下学期的
    学费、杠杆借来的钱都是"急钱"，不能用来做长期投资；只有"时间充裕的钱"
    （5年内用不到）才能等待复利成熟。投资前先给每一分钱贴"时间标签"。
  tags: [decision, time, investment]

- id: f04
  title: 风险最大时风险最小（逆向风险框架）
  type: framework
  source_chapter: 风险最大的时候也是风险最小的时候
  source_quote: |
    "市场处于熊市时……风险看起来十分巨大，因此没有人购入股票，导致股价暴跌。但
    这一时期其实是风险降低得最多的时期。……看似风险消失的牛市当中反而存在着最大的风险。"
  summary: |
    风险与大众感知负相关：人人恐惧、无人购买、股价跌破价值时，风险反而最低；
    人人贪婪、泡沫膨胀时，风险最高。操作上：恐惧时按价值分批买入（看内在价值而非
    价格），贪婪时警惕。巴菲特"别人贪婪我恐惧"是同一模型的极端版。
  tags: [mental-model, risk, contrarian]

- id: f05
  title: 教练 vs 选手（资产配置优先框架）
  type: framework
  source_chapter: 是教练（资产分配）重要，还是选手（位置）重要
  source_quote: |
    "我认为，在投资方面，教练比选手重要得多。如果表达得较为极端一些，可以说，
    做好资产配置就是投资的全部。……希望你能把相当于9倍关注投资产品的精力倾注到资产配置上。"
  summary: |
    把投资比作足球队：资产配置是"教练"（多少本金、什么钱、投多久、分几类资产），
    选具体标的/择时是"选手"。普通人把精力全花在"选哪只股票"（选手）上，
    而收益的大头其实由资产配置（教练）决定。先做配置，再谈标的。
  tags: [decision, asset-allocation, portfolio]

- id: f06
  title: 篮子 vs 架子（分散投资的真伪）
  type: framework
  source_chapter: 鸡蛋没放进一个篮子，为什么还是都碎了
  source_quote: |
    "购买多只股票其实就是多分了几个篮子而已，最终还是相当于把这些篮子都放在了一个
    架子上。架子不是也有倒塌的时候吗？"
  summary: |
    分散投资要跨"架子"（资产大类：存款/债券/股票/房地产/实物）而不是只在一种
    资产内买多只（那样只是把鸡蛋分装进同一架子的多个篮子）。全部押注楼市或全部
    押注股市都不算分散。作者做法：聚拢资产时集中，让资产生资产时分散。
  tags: [decision, diversification, risk]

- id: f07
  title: 固定收入 > 不固定收入（现金流质量框架）
  type: framework
  source_chapter: 固定收入的金钱具有强大力量
  source_quote: |
    "固定收入的金钱的质量要高于不固定性收入的金钱的质量。质量高的金钱能够召唤聚拢
    其他金钱。……只有稳定地维持现金流量，生活才会变得富足。"
  summary: |
    衡量一笔收入，金额其次，"节奏"更重要：固定、可预测的现金流（工资、房租、分红）
    质量高，能控风险、带来信用；一次性的大钱（暑期暴利、偶尔中奖）质量低、易挥霍。
    收入不固定者应尽早把收入转移到"固定收入资产"（出租房/绩优分红股）上。
  tags: [framework, cashflow, income]

- id: f08
  title: 良债 vs 劣债（债务分类框架）
  type: framework
  source_chapter: 良债，劣债
  source_quote: |
    "从自己的腰包里把钱掏走的债务是劣债，给自己带来金钱的债务是良债；自己无法掌控的
    负债是劣债，在自己控制范围内运转的负债是良债。"
  summary: |
    债务不是绝对的恶，关键是分类：用于产生收益且收益（ROE）高于利息、现金流能覆盖、
    自己可控的债务是良债（能加速扩张）；用于消费、不可控、利息吞噬现金流的债务是
    劣债（绞索）。负债的性质由"你怎么用它"决定，不是天生善恶。
  tags: [decision, debt, leverage]

- id: f09
  title: 接住落下的刀（价值投资框架）
  type: framework
  source_chapter: 能抓住落下的刀的人
  source_quote: |
    "为了能抓住落下的刀，要了解公司的价值而不是价格。当市场价格跌落至价值以下时，
    要分批买入。……皮手套的一只是分批买入，另一只是对企业价值的信心。"
  summary: |
    当恐慌导致股价跌破内在价值时，不是"别接飞刀"，而是"戴皮手套接刀"：了解公司
    价值（看财报而非股价）、分批买入、不用杠杆、在合理价值以下买。前提是懂企业价值；
    不懂价值的人接刀才是赌博。
  tags: [decision, value-investing, contrarian]

- id: f10
  title: 不认路就走大路（走大路/第一原则）
  type: framework
  source_chapter: 不认路就走大路
  source_quote: |
    "我只买从地铁站出来后一眼就能看到的建筑。这样的地段，当天贴上招租或出售公告，
    当天就有人来联系。……最贵的也就是最便宜的。"
  summary: |
    在自己不精通/不专业的领域，放弃抄近道，走"大路"：买楼只买地铁站旁一眼可见的
    位置，买股只买行业第一（后来才是第二），不碰第三。大路牺牲一点成长空间，
    但避免"只错一次就出局"的致命错误。收益低于是平均水平不叫穷，回不了场才是。
  tags: [decision, conservative, first-principle]

- id: f11
  title: 腹八分（留余量/不贪框架）
  type: framework
  source_chapter: 头凉足暖腹八分
  source_quote: |
    "赚钱时要勤奋地东奔西走、考察现场……花钱时要在清醒、理性地判断之后再支付，
    投资时不要贪得无厌，就好比在肚子饱之前就起身是最为长久地维持健康生活的方法。"
  summary: |
    把养生训诫"腹八分"（吃八分饱）迁移到赚钱、攒钱、投资：投入前先留余量、
    卖出时不要等"吃满最后一分钱"（贪婪会导致卖不出）。不贪婪才能最长久地获利。
  tags: [mental-model, moderation, risk]

- id: f12
  title: Quarter 准则（消费尺度框架）
  type: framework
  source_chapter: Quarter准则
  source_quote: |
    "收入10万美元的人，像收入2.5万美元的人那样生活；收入100万美元的人，像收入
    25万美元的人那样生活。……是为了在资产增长不确定的状况下，如果发生经济问题，
    没有收入也能够维持3年的生活。"
  summary: |
    在"极端节俭（巴菲特式）"和"炫耀奢侈"之间设一个可执行标准：生活水平保持在与
    自己同等收入者的 1/4。这样既允许适度享受（奖励机制），又为危机留下至少 3 年
    的生存缓冲。衡量"消费是否过度"的可操作标尺。
  tags: [framework, consumption, frugality]

- id: f13
  title: 个人独立纪念日（资本收入 > 劳动收入）
  type: framework
  source_chapter: 我的独立纪念日在何时
  source_quote: |
    "把收入积攒起来形成资产，而后再生出其他资产……生出且被维护的资产的规模超过
    劳动所得的那天就是个人独立纪念日。"
  summary: |
    把"经济自由"定义为一个可纪念的具体节点：资本收入（资产产生的被动收入）首次
    超过劳动收入的那一天。它把抽象目标变成可倒逼的行动计划（先攒种子钱、再让资产
    生资产），并给出一个清晰的"我是否独立了"的判定标准。
  tags: [framework, freedom, goal]

- id: f14
  title: 漂亮的垃圾（消费诊断框架）
  type: framework
  source_chapter: 漂亮的垃圾
  source_quote: |
    "有很多东西当时看着漂亮、想要拥有，但带回家中却没有合适的地方放置，日后丢掉又
    十分可惜，就这样成了漂亮的垃圾的东西可不止一两件。"
  summary: |
    在购买前先判断它是不是"漂亮的垃圾"（买时漂亮、带回家无处安放、弃之可惜的物品）。
    富人的消费从"为了炫耀"转向"因为需要"：奢侈品可有可无，真需要的是体验、回忆
    和好的睡眠/椅子/床。用这个过滤器拦截冲动消费。
  tags: [decision, consumption, minimalism]

- id: f15
  title: 能久与功夫（持续 100 天改变框架）
  type: framework
  source_chapter: "能久"和"功夫"
  source_quote: |
    "无论做什么，只要坚持不懈地实践3个月，那么这件事的本质就会发生变化。……
    再困难也要坚持100天。如果坚持100天有难度，那就坚持3个月。"
  summary: |
    把"改变自己"降维成"持续行动 100 天/3 个月"：无论减肥、戒烟、学投资还是锻炼，
    都先定一个 3 个月/100 天的持续周期。能坚持下来就证明可以改变；过程中身体、
    心灵、思维都会变化，习惯由此养成。给"改变"一个可执行的期限刻度。
  tags: [framework, habit, self-change]

- id: f16
  title: 农夫与渔夫（积累/投资双模式）
  type: framework
  source_chapter: 积累财产时做农夫，投资时做渔夫
  source_quote: |
    "富人们在积累财产的时候像农夫一样，向下深挖土地，等待雨水，克服干旱，长久坚持。
    而当他们赚到钱，拥有了资产之后，就会像渔夫一样奔波。"
  summary: |
    两种不同的行为模式：积累财产阶段像农夫——耐心、深挖、长期坚持；投资运作阶段
    像渔夫——跟随市场变化快速调整、根据风向水温决定在哪里撒网。判断当下该用哪种
    模式，决定你是"深挖不动"还是"频繁调整"。
  tags: [mental-model, wealth, adaptability]

- id: f17
  title: 大富由天（运气认知框架）
  type: framework
  source_chapter: 大富由天
  source_quote: |
    "我能够在事业上获得成功也少不了运气。……我比其他人的突出之处只有一点，
    那就是我知道运气的存在。"
  summary: |
    承认"小富由勤，大富由天"：勤奋是必要条件不是充分条件，大富依赖时代窗口、
    行业周期与运气的偶合。知道运气存在，才能对已有财富保持感恩与谦逊，也才不会
    把一次成功误当成可复制的实力。核心是"知道运气的存在"本身。
  tags: [mental-model, luck, humility]

- id: f18
  title: 弱者的策略（差异 + 速度）
  type: framework
  source_chapter: "穷二代"战胜"富二代"的方法
  source_quote: |
    "强者具有强者的弱点。正因为这一弱点……弱者变换策略并辅以高效的执行力，
    成功的概率自然会有所提高。……寻找差异并迅速行动是弱者的优势。"
  summary: |
    历史是弱者战胜强者的记录（赤壁、鸣梁、沃尔玛/苹果当年的弱小）。强者弱点：
    规模大→感知变化慢→行动迟缓。弱者优势：体量小→能快速变换策略→执行力高。
    穷二代不必畏惧富二代——大象倒下难起身，狐狸能跳十次。打法是"差异+速度"。
  tags: [mental-model, strategy, underdog]

- id: f19
  title: 新闻 vs 投资信息（看比率不看总数）
  type: framework
  source_chapter: 通过新闻区分事实和投资信息的方法
  source_quote: |
    "我关注的不是感染总数，而是感染比例。以感染比例为标准，当最高峰值过去之后，
    新冠肺炎疫情得到了控制。"
  summary: |
    区分"事实"与"投资信息"：新闻往往用总量（感染总数、失业总数）制造恐惧，
    而判断趋势要看比率（感染增长率、边际变化）。作者在2020年3月恐惧最高峰买入，
    依据的正是"感染比例下降"这一边际信号而非总数。数字要拆开看分母。
  tags: [framework, information, contrarian]

- id: f20
  title: 投资赢家资格 11 问（投资资格自测框架）
  type: framework
  source_chapter: 判断是否具备投资赢家资格的11个问题

  tags: [framework, checklist, qualification]
