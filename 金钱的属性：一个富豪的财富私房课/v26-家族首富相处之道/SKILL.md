# 家族首富相处之道：按资产规模分级支援家人

## R — 原文 (Reading)

> 情况1（不足10亿元）：不该借钱给兄弟们创业、帮父母换房换车；该给照顾父母的嫂子买名牌包、侄子侄女入学买电脑、聚餐全额付餐费、定期给父母生活费。……情况3（超过100亿元）：帮助兄弟脱贫、让家族富起来。
>
> — 金胜镐, 《成为家族首富时对待父母与兄弟的行动要领》

## I — 方法论骨架 (Interpretation)

**家人中出现富人，处理不好就会隔阂、失落、责难**。核心原则：**按资产规模分级支援，先稳住家庭结构，再谈帮扶**。

三个情景（以资产规模分档）：

1. **<10亿（初步富裕）**：**不做**大额支援（不借巨款给兄弟创业、不帮父母换房换车）；**做**小额关怀（给照顾父母的嫂子买包、给侄子侄女买入学电脑、聚餐买单、定期给父母生活费）。"这个时期不是支援家人的时期，而是避免家人人心涣散的时期"。给父母生活费要固定日期准时转账、说"投资收益"不说"生活费"。
2. **<50亿**：可承担父母房/车与全部生活费用、帮侄子侄女付学费；对兄弟的支援仍要小心（相对直接借资金，给侄子侄女付学费更贤明）。
3. **>100亿**：有责任让整个家族富起来——选有企业家资质的兄弟给一部分企业实体管理；每年送父母旅行（连同父母的朋友）；对亲戚红白事/住院承担"保险经纪人"角色。**所有经手通过配偶完成**，让配偶在家族中获得相应待遇。

## A1 — 书中的应用

- 作者从自身失误中总结：他列出三情景，强调"给父母的生活费要像发工资一样固定日期准时自动转账，哪怕晚一天父母就会多心"。
- 作者建议给父母生活费时"用语不要说是生活费，要说成是投资收益"（他们年轻时给子女投入的价值的收益分红），让他们毫无负担地接受并花掉。
- 作者提醒：兄弟借钱创业、买房借款、生活费救济等请求，在自己资产未稳固前"绝不应允"——"自己还没从水中逃出却被抓住脚脖子，只会让大家一同深陷困窘"。

## A2 — 触发场景 ★

**场景**：你成为家里第一个"比较有钱"的人；家人向你借钱/请求支援时；你纠结"该帮父母买房/帮兄弟创业吗"；你想在富裕后维持家庭和睦时。

**语言信号**：
- "亲戚向我借钱，该借吗？"
- "我富了，该给爸妈买房子吗？"
- "兄弟想让我担保/投资他创业，怎么办？"
- "怎么有钱了还不伤家庭和气？"

**相邻区分**：与"对待他人金钱"（v19）配合——尊重家人金钱是本 skill 的价值观基础；与"良债vs劣债"（v07）配合——"借钱给兄弟"本质是处理"家庭借贷"；与"富人四种能力"（v02）配合——本 skill 是"保值/消费"能力在家庭维度的延伸。

## E — 执行步骤

1. **认清自己的档位**：估算你的净资产规模，确定处于哪个情景（<10亿/<50亿/>100亿的本地相对版——按你所在地购买力换算）。

2. **执行"该做/不做"清单**：按档位执行：<10亿档——只做小额关怀、设立"不借巨款/不担保"的底线；给父母设固定日期的生活费自动转账。

3. **设置家人财务边界**：明确对兄弟的支援边界（不借巨款、不做担保、不包养），用"帮助侄子侄女/照顾父母"的迂回方式表达亲情。

4. **让配偶经手 + 全家同步**：所有给家人的金钱经配偶之手；向父母/家人说明金钱来自"共同的家"，避免因钱生隙；随资产增长逐步升级支援档位。

## B — 边界 ★

- 作者的三档金额（10亿/50亿/100亿韩元）是韩国背景，需按你所在地购买力折算；核心是"分级、克制、先稳结构"的原则。
- 每个家庭文化不同：有的家庭"帮兄弟"是常态、有的边界感强；本 skill 是作者的个体经验，需结合你的家庭情况调整。
- 别因"该给父母生活费"而被原生家庭过度索取（扶弟魔式困境）：作者也强调"先把自己的子女和配偶照顾好"。
- 本 skill 是价值观/边界框架，不是法律建议；涉及大额财产安排（遗嘱、信托）请咨询专业人士。
