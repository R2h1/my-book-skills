# "大家都在做"反向指标框架

## R — 原文 (Reading)

> 如果每个人都去做同样的事情，肯定会失败。谈到金钱，最好的警示信号就是"大家"。这是一个红色警告，说明进入戒律被打破了。如果每个人都去做同样的事情，肯定会失败。当一般公众中出现了投资的非理性繁荣时，我就知道这是该退出和旁观的时刻了。当羊群排着队走向屠宰场时，你应该是那个屠宰场的主人。
> — MJ·德马科, 第31章

## I — 方法论骨架 (Interpretation)

这是一个利用从众行为作为反向信号的推理方法。核心逻辑链条：

1. "大家都在做" = 低进入壁垒的赛道
2. 低进入壁垒 = 大量供给涌入
3. 大量供给 = 竞争激烈、利润微薄
4. 利润微薄 = 绝大多数人赚不到钱

换句话说：当大众非理性涌入某个领域时，正是最危险的时刻。科技股泡沫、房地产泡沫、比特币狂热——每次泡沫都有一批跟风者最后买单。

关键洞察：**真正赚钱的不是跟随者，而是最早进入的创立者和"卖铲子"的人。** 当出租车司机和水暖工都在讨论某个投资时，"傻钱"已经入场，该退出了。

这个框架不是让你永远不做热门事，而是让你在进入前先问："大家'是谁？如果'大家'是缺乏专业判断能力的普通大众，这就是警示信号。"

## A1 — 书中的应用 (Past Application)

**历史泡沫案例**：作者列举了"大家都在做"导致的繁荣和崩溃：科技股泡沫（人人买互联网股票）、油价暴涨、房地产崩溃（水暖工吹嘘3处出租物业升值15%）、全球金融崩溃——都是典型的"大家都在做"导致的反向指标。

**作者的加盟计划经验**：作者网站的加盟计划中，最好的加盟商月入2万美元——不错的收入。但作者作为系统所有者（创立者）月入20万美元——大钱。跟风者赚零头，创立者赚大头。这就是"大家都在做"数学上的必然结果——供给端拥堵导致利润被摊薄，只有顶层的人赚到钱。

## A2 — 触发场景 (Future Trigger)

**触发场景**：
1. 你看到一个投资/创业机会看起来特别火热时
2. 你发现身边人（同事、亲戚、邻居）都在做同一件事时
3. 媒体开始铺天盖地报道某个"人人都能赚钱"的机会时
4. 你感觉"再不进场就晚了"的焦虑时

**语言信号**：
- "现在大家都在做XX"
- "连XXX都在投资这个"
- "这是一个热门行业，人人都能赚钱"
- "这是未来趋势，不跟上就落后了"
- "我认识的每个人都买了XX股票"

**与相邻skill的区分**：这个skill关注"是否应该进入一个热门赛道"，是事前的评估。v08-进入戒律关注的是"这个生意本身的壁垒高低"，更偏向具体的业务分析。两者互补但不重叠——"大家都在做"是一个快速筛查信号，进入戒律是更细致的检查。

## E — 可执行步骤 (Execution)

当技能被激活后，按以下步骤执行：

1. **识别"大家"群体**：谁在说"大家都在做"？是行业专家还是普通大众？出租车司机、亲戚、同事都在讨论时，警惕度拉到最高。
2. **分析进入时机**：这个领域已经发展到了哪个阶段？早期（少数人做）→ 增长期（越来越多）→ 狂热期（人人讨论）→ 崩盘期。在狂热期进入几乎必亏。
3. **检查利润结构**：这个领域的钱被谁赚走了？是顶层创立者（平台所有者）还是底层参与者（内容创作者、分销商、小投资者）？如果绝大部分利润流向顶层，底层只是在"陪跑"。
4. **寻找"卖铲子"的机会**：与其加入拥挤的主赛道，不如看看赛道周边——服务这些参与者的人往往比参与者更赚钱。
5. **做反向推理**：如果"大家"都认为这件事会涨，那么谁来接最后一棒？如果没有人了，说明价格已经到顶。
6. **建立个人纪律**：每当你想追热点时，强制等待72小时再做决定。冲动过后，用5条戒律重新评估。

## B — 边界 (Boundary)

**不适用场景**：
- 你已经通过5条戒律（NEEDS）验证的方向，即使很多人做也不代表你该放弃——你可能是那个做得更好的人。
- 技术创新早期（如AI基础模型）——"大家都在做"时可能还处于技术扩散初期，真正的泡沫还没来。
- 公益/非营利领域的从众行为——反向指标框架主要针对财富创造场景，不适用于社会运动。

**失败模式**：
- 把"有人在做"等同于"不能做"——竞争存在不等于无法进入，关键是你的执行力和差异化。
- 反向指标走火入魔——对所有热门事物都自动回避，错过了真正的大趋势（如2009年的比特币、2015年的云计算）。
- 以为自己每次都能精准判断泡沫顶点——事实上，泡沫可以持续很长时间，过早退出同样损失机会。

**作者盲点**：
- 过于强调从众风险，忽略了"从众也可能理性"——当技术革命真的来临时，跟随趋势是正确的。
- 低估了在热门赛道中通过差异化竞争获胜的可能性——谷歌不是第一个搜索引擎，但赢了。
- 作者写书时（2011年）的泡沫判断标准在社交媒体的时代可能已经变化——信息传播速度加快使得"大家都在做"的信号出现更早、更频繁。
