# 摇钱树五种苗分类

## R — 原文 (Reading)

> 摇钱树是一种商业系统，它是快车道路线图中的主要街道。摇钱树在你"正式"退休前为你创造出被动收入流。……不是所有的生意都是快车道，许多生意无法转换成摇钱树。受到那些专家和生活导师的影响，想要成为企业家被误导为"成为自己的老板"，或者"做你喜欢做的事情"，其结果是不得不低头成为生意的奴役，这和签约一份工作并无不同。
>
> — MJ·德马科, 第19章

> 有5种生意的苗木可以成长为摇钱树。请注意，这不是绝对的，它们彼此间也杂交繁殖。每一个系统都有一个等级，它决定了被动性的级别。等级越高意味着被动性越高，但其收入不一定越高。租赁系统（被动等级A）、计算机/软件系统（被动等级A-）、内容系统（被动等级B+）、分销系统（被动等级B）、人力资源系统（被动等级C）。
>
> — MJ·德马科, 第19章

## I — 方法论骨架 (Interpretation)

德马科将快车道业务分为五类，按"被动性"（即业务在多大程度上不需要你亲自投入时间）评级。核心判断标准是：**这个业务在你睡觉/度假/生病时，是否还能产生收入？**

五种苗木按被动性从高到低排列：

1. **租赁系统 (A级)**：你拥有资产（房地产、专利、版权），别人使用它并付钱。你几乎不需要介入运营。收入取决于资产规模和利用率。
2. **计算机/软件系统 (A-级)**：代码或网站7x24小时运行，无需你操作。复制成本趋近于零，边际利润极高。收入取决于用户/流量规模。
3. **内容系统 (B+级)**：信息产品（书、课程、博客）一旦创建，可反复销售。时间投资集中在前期，后期维护成本低。收入取决于受众规模和信任度。
4. **分销系统 (B级)**：你将产品送达消费者的渠道（特许经营、连锁、网络营销、电视购物）。前期需要搭建渠道，后期靠系统运转。收入取决于渠道覆盖面和效率。
5. **人力资源系统 (C级)**：靠管理他人来运营业务。被动性最低，因为人需要管理、培训、激励、监督。收入取决于团队规模和执行力。

关键洞察：五种苗木可以混合。如亚马逊=计算机系统(网站) + 分销系统(物流) + 人力资源系统(员工)。混合时被动性取最低值。

## A1 — 书中的应用 (Past Application)

**案例：姬莉安的熟食店（反面案例——不是摇钱树）**

姬莉安辞去华尔街工作，加盟了一家知名熟食店（特许经营）。她每周工作7天，每天超长时间，两年下来精疲力竭。利润被特许经营费蚕食，根本无力雇人打理。虽然每年赚9万美元利润，但她完全没有自由时间。如果她花6万美元请人管理，自己只剩3万美元无法生存。她的"生意"实际上是伪装的"工作"——不是摇钱树。

**案例：德马科的互联网公司（计算机系统+分销系统）**

德马科的互联网公司85%是被动收入。电脑24小时工作，不需要他操作。即使在他赌博输钱、躺在床上看《法官朱迪》、在牙买加滑雪时，系统都在赚钱。这是计算机系统和分销系统结合的典范。

**案例：机场停车场计划（反面案例——被否决）**

德马科研究过在机场附近做停车场的生意。从商业模式看是租赁系统（A级），但运营需要24名员工，实际上变成了人力资源系统（C级）。被动性从A降到C，他因此放弃了这个计划。

**案例：莱斯丽·沃尔本的流浪狗庇护所梦想**

莱斯丽对动物感兴趣，梦想拥有流浪狗庇护所。她没有直接去做"喜欢的事"（那会违背需求戒律），而是先建立一个与动物无关的快车道业务，用赚来的钱为梦想融资。这是"先建摇钱树，再实现梦想"的典型案例。

## A2 — 触发场景 (Future Trigger) ★

**典型触发场景：**
- 你在考虑创业方向，但不确定哪种模式能产生被动收入
- 你已经在经营一个业务，但发现自己被"绑"在业务上无法脱身
- 你在评估一个加盟机会/代理机会/直销机会
- 你想优化现有业务的被动性，但不知道从何入手

**语言信号：**
- "这个生意需要我每天亲自……"
- "我不在的时候业务就停了"
- "我要雇人，但怕他们做不好"
- "我想找个不用操心的生意"

**与相邻技能区分：**
- 与 v15（执行vs点子）的区别：v15告诉你"先执行，不要等完美点子"；v23告诉你"选择哪种业务结构来执行"——v15破除行动障碍，v23提供行动方向。
- 与 v16（明智风险）的区别：v16帮你评估"这个风险该不该冒"；v23帮你评估"这个业务模式的被动性够不够高"——v16是风险维度，v23是结构维度。

## E — 可执行步骤 (Execution)

当技能被激活后，按以下步骤执行：

1. **识别你的业务苗木类型**：用五种分类评估你正在考虑或正在做的业务属于哪一类。如果是混合型，列出各成分及其占比。

2. **计算被动性指数**：评估"如果你完全不工作一个月，这个业务还能产生多少收入？"被动性 = 无人值守时月收入 / 有人值守时月收入 × 100%。目标：被动性 ≥ 60%。

3. **升级被动性**：如果被动性过低，问自己：能否从C级升级到B级（将管理流程系统化）？能否从B级升级到A级（从运营转为资产拥有）？能否加入一个A级成分（如增加软件/租赁元素）？

4. **排除伪摇钱树**：用以下问题检验你的业务是否是真正的摇钱树——"如果我现在出车祸住院3个月，我的业务会怎样？"如果答案等于"会倒闭"，这就是一份伪装的工作，不是摇钱树。

5. **多苗木策略**：不要只依赖一种苗木。先建立一个核心摇钱树（如计算机系统），再用产生的现金流投资另一种苗木（如租赁系统）。德马科走的就是这条路径：互联网公司 -> 现金 -> 债券/市政债券。

## B — 边界 (Boundary) ★

**不适用场景：**
- 当你还在职业探索期时：五类苗木框架适用于已经决定"走创业路线"的人，不适用于还在"打工vs创业"犹豫阶段的人。
- 当你资金极度匮乏时：某些苗木（如租赁系统）需要大量启动资金，计算机系统需要技术能力，人力资源系统需要管理经验。根据自身资源选择。

**失败模式：**
- **被动性崇拜**：过度追求被动性而牺牲收入和增长。人力资源系统被动性低，但亚马逊、麦当劳都是靠人力资源系统成为巨头的。被动性不是唯一指标。
- **混合陷阱**：试图同时做五种苗木，结果哪一样都没做好。应该先专注一种，再做横向扩展。
- **过度自动化**：过早用系统替代人的判断，导致业务僵化。被动性应该在业务模式验证后再优化。

**作者盲点：**
德马科的被动性评级带有个人偏好——他厌恶人力资源系统，因为他自己不愿管人。但世界上最大的公司都是人力资源密集型。评级应该是"适合你的被动性偏好"，而不是绝对的优劣排序。对于擅长管理的人来说，C级业务可能比A级业务更高效。
