# 小狗钱钱 — 书籍概览

## 书籍简介

《小狗钱钱》是全球最著名的儿童理财童话，作者博多·舍费尔也是《财务自由之路》的作者。

故事讲述12岁女孩吉娅救了一只受伤的白色拉布拉多犬并取名"钱钱"。钱钱是一只会说话的理财天才狗，它教会吉娅关于金钱的种种秘密：从梦想清单、成功日记到如何储蓄、投资。吉娅不仅自己掌握了理财方法，还帮助父母走出财务危机。

## 核心思想

1. **金钱是中性的** — 既不好也不坏，放大人的本性
2. **富裕是与生俱来的权利** — 财务自由是每个人都可以实现的目标
3. **理财是思维方式** — 不是技术问题，而是如何看待自己和金钱
4. **从小开始** — 儿童比成人更容易掌握理财规律
