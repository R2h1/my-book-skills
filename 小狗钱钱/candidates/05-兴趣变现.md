# 兴趣变现（概念候选）

## 核心内容
1. 想清楚自己喜欢做什么，然后考虑如何通过它挣钱
2. 把精力集中在你能做的、知道的、拥有的东西上
3. 不要总想着做不到的事情，去找行得通的机会
4. 为别人解决一个难题，你就能赚到钱

## 原理
大多数人把时间花在想自己不能做的事上，而成功的人专注在自己能做的事上。孩子之所以能比成人挣更多钱，是因为他们没有成人的自我设限。

## 出处
- 第3章：达瑞的故事（为邻居送报纸、倒垃圾）
- 第4章：马塞尔通过骑车送面包挣钱
- 第4章：吉娅通过遛狗挣钱
- 第6章：汉内坎普先生"做自己喜欢的事才能真正成功"
- 第7章："你为什么不能因为做了一件自己喜欢的事情而挣到钱呢？"
