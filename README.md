# My Book Skills

书籍知识蒸馏为 Claude Code 可执行技能（Skill）的集合仓库。

每本书通过 [RIA-TV++ 管道](https://github.com/R2h/cangjie-skill) 蒸馏为一组结构化技能文件，可直接在 Claude Code 中使用。

## 使用方式

将书目录放入 Claude Code 的 `skills` 目录后，通过 `/技能名` 调用对应技能：

```bash
# 复制到用户级 skills 目录（推荐）
cp -r <书目录> ~/.claude/skills/

# 或复制到项目级 .claude/skills/
cp -r <书目录> <项目路径>/.claude/skills/
```

### 示例

调用《30岁人生开挂7步法》中的「摆脱自我意识三步法」：

```
/摆脱自我意识三步法 我看到别人赚钱就酸，怎么办？
```

调用《小狗钱钱》中的「梦想清单与视觉化」：

```
/梦想清单与视觉化 我不知道该为什么存钱
```

## 技能格式（RIA++）

每个 `SKILL.md` 遵循 RIA++ 模板：

| 部分 | 含义 | 说明 |
|------|------|------|
| **R** | Reading | 核心引文 — 书中原文摘录 |
| **I** | Interpretation | 底层原理 — 方法论重述 |
| **A1** | Past Application | 过去应用 — 书中案例与实证 |
| **A2** | Future Triggers | 未来触发 — 何时使用该技能 |
| **E** | Execution Steps | 可执行步骤 — 行动指南 |
| **B** | Boundary | 边界与局限 — 不适用场景 |

## 目录结构

每本书按以下结构组织：

```
<书目录>/
├── v01-技能一/       # 每个技能独立目录
│   └── SKILL.md     # RIA++ 格式的技能定义
├── v02-技能二/
│   └── SKILL.md
├── ...
├── candidates/       # 候选概念（Stage 1）
├── rejected/         # 未通过验证的提案
├── INDEX.md          # 技能关系网络、依赖、使用路径
├── BOOK_OVERVIEW.md  # 书籍概览与蒸馏说明
├── test-prompts.json # 技能触发测试用例
├── verified.md       # 三重复核记录（V1-V3）
├── *.epub / *.txt    # 原始书籍源文件
└── extract_book.py   # 可选的提取脚本
```

### 技能命名规范

- `vXX-name` 格式，如 `v01-摆脱自我意识三步法`
- 按书中章节或主题顺序编号，技能间存在前置依赖关系

## 验证流程

每个技能候选需通过三重验证方可写入 SKILL.md：

- **V1（跨域证据）**: 书中存在多个独立案例或跨场景证据
- **V2（预测能力）**: 技能能在新场景中给出可操作的指导
- **V3（排他性）**: 与其他技能有清晰的边界
